# 🎬 Swetha Talkies – Movie Recommendation Chatbot

**Swetha Talkies** is an intelligent chatbot that provides personalized movie recommendations based on user preferences. Developed with a frontend in **React (TypeScript)** and a backend powered by **Python**, it uses a dataset-driven approach to suggest the right films for your mood.

## 🔍 Features

- 💬 Conversational chatbot UI
- 🎞️ Movie recommendations based on genre, language, and mood
- 🧠 Smart filtering using Python-based dataset processing
- ⚡ Fast and responsive frontend with React + TypeScript
- 🔗 Clean API integration between frontend and backend

---

## 🛠️ Tech Stack

| Frontend | Backend  | Other |
|----------|----------|--------|
| React (TypeScript) | Python (Flask or FastAPI) | Movie dataset (CSV/JSON) |
| Tailwind CSS / Bootstrap | Pandas / NumPy for data handling | Axios for API calls |
